# Release Notes

## 0.1.0-online-alpha

- Added account-free QR and room-code joining.
- Added host, public display, and mobile player interfaces.
- Added server-authoritative Copperline room state and dice checks.
- Added six planning roles, six factions, evidence, commitments, hearing challenges, and epilogues.
- Added same-device reconnection, host recovery, room locking, and 24-hour expiry.
- Added host-only after-action JSON export.

This release is intended for controlled playtesting. It has not yet passed the two-session
promotion gate defined in `ROADMAP.md`.
