# Security Policy

## Supported version

Only the latest tagged alpha release is supported.

## Reporting

Do not open a public issue for a vulnerability that could expose room credentials,
facilitator-only content, or participant data. Report it privately to the repository owner
through GitHub's private vulnerability reporting feature.

Never include production tokens, room recovery links, participant cookies, or personal
information in an issue or pull request.

Temporary game rooms expire after 24 hours. Players should use display names rather than legal
names.
