# Asset Provenance

Version 0.1.0 includes no third-party illustrations, photographs, audio, video, or font files.

- The interface artwork consists of original CSS shapes and typography using system fonts.
- QR images are generated at runtime from the room join URL by the MIT-licensed `qrcode` package.
- Written Copperline material is original project content and is covered by
  `LICENSE-CONTENT.md`.

Record the creator, source URL, acquisition date, modifications, and license here before adding
any external visual or audio asset.
