# Ready-to-Play Characters

Print or copy one character section for each player. Use any four to six characters. Missing professions are represented by staff reports and may never block completion of the scenario.

Attribute ratings run from 0 to 3. Add `+2` when a listed specialty clearly applies.

---

## Rowan Vale — Comprehensive Planner

**Role:** Connect policies, people, and long-term outcomes.

| Attribute  | Rating |
| ---------- | -----: |
| Analysis   |      2 |
| Empathy    |      2 |
| Persuasion |      2 |
| Procedure  |      2 |
| Vision     |      3 |
| Resilience |      1 |

**Specialties**

- Policy Alignment
- Scenario Building
- Plan Synthesis

**Professional move — Connect the Plans**

After any check, cite two pieces of discovered evidence that point toward the same conclusion. Improve the result by one category: setback to mixed, mixed to success, or success to breakthrough.

**What you know**

Bellwether’s adopted comprehensive plan directs at least 40% of new housing toward existing or planned transit corridors. The policy supports growth at Copperline, but it also requires anti-displacement measures in vulnerable neighborhoods.

**Prompt**

Ask: “What future does this decision make easier—and what future does it foreclose?”
